📶 Fluvius-sync — bookmarklet installeren

v2 · Eén tik op mijn.fluvius.be (ingelogd) → alle Fluvius-info van je meters (IMBY-mandaten én Eigen meters: status, adres, metertype, label, toegangen) staat op je klembord → plak ze in de Mandaten-app onder Plak → Sync. Werkt op iPhone en desktop. Geen agent, dus nooit geblokkeerd.

1 · Kopieer de bookmarklet

Desktop-tip: sleep i.p.v. te kopiëren deze knop naar je bladwijzerbalk → 📶 Fluvius → Fluctus sync

2a · Op iPhone (Safari)

  1. Kopieer eerst de bookmarklet hierboven (knop Kopieer).
  2. Ga naar een willekeurige pagina, tik het deel-icoon → Bladwijzer → Bewaar (naam bv. "Fluvius sync").
  3. Open Bladwijzers → Wijzig → tik op die nieuwe bladwijzer.
  4. Wis het adres en plak de gekopieerde bookmarklet als het adres. Bewaren.
  5. Later: op mijn.fluvius.be (ingelogd), tik in de adresbalk je bladwijzer "Fluvius sync" aan.

2b · Op desktop (Chrome/Safari/Edge)

  1. Sleep de blauwe knop hierboven naar je bladwijzerbalk (of maak een nieuwe bladwijzer en plak de code als URL).
  2. Ga naar mijn.fluvius.be/verbruik (ingelogd).
  3. Klik de bladwijzer → hij haalt meteen alle IMBY-mandaten op (ook de nog niet goedgekeurde).
  4. Klik daarna even de tab Eigen meters (en Meters van anderen) of Filter → Toepassen → de teller in het blauwe kader loopt op met de meters die niet via IMBY lopen.

3 · Syncen

  1. Staat er "Toegang zoeken…" → klik de tab Eigen meters of doe Filter → Toepassen; de bookmarklet pikt dan de toegang op.
  2. Klopt de teller (bv. alle meters uit "67 van 67")? Klik Kopieer.
  3. Open de Mandaten-app → knop 📋 Plak → Sync → plak → Sync nu.

Per EAN komen status (actief / aangevraagd / geannuleerd), referentienummer, Fluvius-adres, metertype, label, bron en de toegangen (dag/kwartier, vanaf, status) binnen; klik in de Mandaten-app op een EAN voor alle velden. Meters die enkel in Eigen meters staan (geen IMBY-mandaat) komen er ook bij. De "Bijgewerkt"-datum = laatste sync.
